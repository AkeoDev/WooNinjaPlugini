# WooNinja - Order Forms

**Verzija:** 2.0.0
**Avtor:** [Humanfrog d.o.o.](https://wooninja.si)

## Opis

Kreiranje dinamicnih narocilnic za WooCommerce. Obrazce je mozno vstavljati na strani ali v prispevke s pomocjo shortcode-ov.

## Zahteve

- WordPress 5.6+
- WooCommerce 5.0+
- PHP 7.4+

Testirano do WordPress 7.0 in WooCommerce 10.7.

## Namestitev

1. Nalaganje vticnika izvedite preko WordPress administracije: **Vticniki > Dodaj novega > Nalozi vticnik**.
2. Aktivirajte vticnik v meniju **Vticniki**.
3. Po aktivaciji ustvarite prvi obrazec v meniju vticnika.

## Nastavitve

Nastavitve vticnika so dostopne v WordPress administraciji:

- **WP Admin > WOF Narocilnice** -- glavni meni vticnika
- Kreiranje novih obrazcev za narocanje
- Urejanje obstojecih obrazcev
- Vstavljanje obrazcev na strani ali v prispevke
