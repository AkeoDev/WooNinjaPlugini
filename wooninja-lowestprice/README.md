# WooNinja - Najnizja cena (PID Direktiva)

**Verzija:** 2.0.0
**Avtor:** [Humanfrog d.o.o.](https://wooninja.si)

## Opis

Prikaz najnizje cene izdelka v zadnjih 30 dneh, skladno z Omnibus direktivo (PID). Vticnik samodejno belezi in prikazuje zgodovino cen, kar zagotavlja skladnost spletne trgovine z zakonodajo EU.

## Zahteve

- WordPress 5.6+
- WooCommerce 5.0+
- PHP 7.4+

Testirano do WordPress 7.0 in WooCommerce 10.7.

## Namestitev

1. Nalaganje vticnika izvedite preko WordPress administracije: **Vticniki > Dodaj novega > Nalozi vticnik**.
2. Aktivirajte vticnik v meniju **Vticniki**.
3. Po aktivaciji prilagodite nastavitve prikaza in preverite licenco.

## Nastavitve

Nastavitve vticnika so dostopne v WordPress administraciji:

- **WP Admin > Najnizja cena** -- glavni meni vticnika
- Nastavitve prikaza najnizje cene na strani izdelka
- Pregled zgodovine cen za posamezne izdelke
- Upravljanje licence
