# WooNinja - Idealno.rs XML

**Verzija:** 1.0.0
**Autor:** [Humanfrog d.o.o.](https://wooninja.si)

## Opis

Jednostavan nacin izvoza proizvoda iz WooCommerce prodavnice u XML format za povezivanje sa uporednikom cena [Idealno.rs](https://www.idealno.rs). Dodatak automatski generise XML datoteku koja se koristi za prikaz vasih proizvoda na Idealno.rs.

## Funkcionalnosti

- Izvoz proizvoda u XML formatu prilagodenom zahtevima Idealno.rs
- Automatski ili rucni izvoz proizvoda
- Podesavanje dostave
- Podrska za UTM parametre
- Upravljanje licencom

## Zahteve

- WordPress 5.6+
- WooCommerce 5.0+
- PHP 7.4+

Testirano do WordPress 7.0 in WooCommerce 10.7.

## Instalacija

1. Uploadujte dodatak u direktorijum `wp-content/plugins/wooninja-idealnors` na vasom serveru ili ga instalirajte direktno preko WordPress interfejsa za dodatke.
2. U WordPress administraciji idite na **Dodaci** i aktivirajte dodatak **WooNinja - Idealno.rs XML**.
3. Unesite licencni kljuc (pogledajte podesavanja ispod).

## Podesavanja

Podesavanja dodatka se nalaze u WordPress administraciji:

**WP Admin > WooNinja - Idealno.rs XML** (glavni meni)

- **Podesavanja izvoza** -- izbor automatskog ili rucnog izvoza, podesavanje dostave, UTM parametri.
- **Licenca** (podmeni) -- unos i aktivacija licencnog kljuca.
