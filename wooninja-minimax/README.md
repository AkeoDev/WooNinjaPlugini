# WooNinja - Minimax

**Verzija:** 3.0.0
**Avtor:** [Humanfrog d.o.o.](https://wooninja.si)

## Opis

MiniMax modul omogoca izdajanje in posiljanje racunov neposredno iz WooCommerce narocil. Podpira sinhronizacijo artiklov, strank in zalog med WooCommerce in MiniMax sistemom.

## Zahteve

- WordPress 5.6+
- WooCommerce 5.0+
- PHP 7.4+

Testirano do WordPress 7.0 in WooCommerce 10.7.

## Namestitev

1. Nalaganje vticnika izvedite preko WordPress administracije: **Vticniki > Dodaj novega > Nalozi vticnik**.
2. Aktivirajte vticnik v meniju **Vticniki**.
3. Po aktivaciji vnesite API podatke za povezavo z MiniMax sistemom.

## Nastavitve

Nastavitve vticnika so dostopne v WordPress administraciji:

- **WP Admin > MiniMax** -- glavni meni vticnika
- API prijava za povezavo z MiniMax racunovodskim sistemom
- Nastavitve racunov in DDV
- Sinhronizacija artiklov in zalog med WooCommerce in MiniMax
- Na posameznem narocilu je na voljo gumb za izdajo racuna
