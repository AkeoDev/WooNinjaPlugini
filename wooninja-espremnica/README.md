# WooNinja - eSpremnica

**Verzija:** 2.0.0
**Avtor:** [Humanfrog d.o.o.](https://wooninja.si)

## Opis

Izvoz narocil v eSpremnica sistem Poste Slovenije. Vticnik omogoca kreiranje nalepk in spremnic za razlicne vrste posiljk.

## Zahteve

- WordPress 5.6+
- WooCommerce 5.0+
- PHP 7.4+

Testirano do WordPress 7.0 in WooCommerce 10.7.

## Namestitev

1. Nalaganje vticnika izvedite preko WordPress administracije: **Vticniki > Dodaj novega > Nalozi vticnik**.
2. Aktivirajte vticnik v meniju **Vticniki**.
3. Po aktivaciji nastavite API podatke in ostale nastavitve.

## Nastavitve

Nastavitve vticnika so dostopne v WordPress administraciji:

- **WP Admin > eSpremnica** -- glavni meni vticnika
- API nastavitve za povezavo z eSpremnica sistemom
- Izbira vrst posiljk
- Konfiguracija dodatnih storitev
- Upravljanje licence
